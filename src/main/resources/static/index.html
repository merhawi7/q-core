State-vector engine2^n complex amplitudes, up to 5 qubits. Gates H, X, Y, Z, S, T and CNOT. Pure Java with its own Complex type, no math library.


Testable by designA SequencePlanner turns a circuit into timed device events with no Spring or network code, so it is unit-tested. The dashboard and the ESP32 use the same timings.


Safe with hardwareDevice calls are asynchronous and best-effort, a new Run cancels the old sequence, and the API works with no hardware attached.

private static Complex[] single(Complex[] s, int n, Operation op) {
    Complex[][] m = op.gate().getMatrix();
    int mask = 1 << (n - 1 - op.target());   // qubit 0 = leftmost bit
    Complex[] out = s.clone();
    for (int i = 0; i < s.length; i++) {
        if ((i & mask) != 0) continue;       // visit each |0>,|1> pair once
        Complex a = s[i], b = s[i | mask];
        out[i]        = m[0][0].times(a).plus(m[0][1].times(b));
        out[i | mask] = m[1][0].times(a).plus(m[1][1].times(b));
    }
    return out;
}
